# Notes

This repository consists of **Jupyter notebooks** with study notes.

They are currently oriented towards:

- **Data Analysis**
- **Machine Learning (ML)**

## Contents

- `src/notes/pandas.ipynb` — essential pandas knowledge (Series, DataFrames, indexing, filtering, data cleaning, groupby, etc.)
- `data/` — sample datasets used by the notebooks

## Setup

```bash
uv sync        # creates/activates the environment (uv)
jupyter lab    # launches Jupyter
```
